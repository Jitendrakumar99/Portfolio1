# Portfolio - Jitendra

Professional full-stack developer portfolio built with React, TypeScript, and Tailwind CSS.

## Live Demo
[https://portfolio1-sooty-eta.vercel.app/](https://portfolio1-sooty-eta.vercel.app/)

## Technologies

- **Frontend**: React, TypeScript, Vite
- **Styling**: Tailwind CSS, Lucide React
- **Animations**: Framer Motion
- **Components**: shadcn/ui

## Project Structure

- `src/components`: UI components (Hero, About, Projects, etc.)
- `src/hooks`: Custom React hooks
- `src/lib`: Core utilities
- `src/pages`: Main application pages

## Getting Started

1. Clone the repository
2. Install dependencies: `npm install`
3. Run development server: `npm run dev`
4. Build for production: `npm run build`
